# search_law 高级检索参考

本文件补充 SKILL.md 的检索策略，提供按法律领域分类的 query 模板、多轮检索组合、调参实战与常见反模式。

## 〇、上手前自检清单

开始检索前，快速过一遍以下检查项，可避免 90% 的常见问题：

- [ ] 已配置 law-search 服务：免登录即可用（内置免费额度），`~/.codebuddy/mcp.json` 已正确写入；需更多额度再注册获取 Key
- [ ] 已**完全退出并重启** CodeBuddy / WorkBuddy（仅关闭窗口无效）
- [ ] query 使用「法条名称 + 核心问题」组合，而非纯口语
- [ ] 空结果时先降 `score_threshold`（0.5 → 0.3）并扩大 `top_k`，不要直接放弃
- [ ] 跨境/国际问题记得切换 `scope: "international"`
- [ ] 遇到网络/超时类错误，按 SKILL.md 1.3 节自动重试，而非立即报错给用户

## 二、多轮检索组合策略

### 场景：用户问"我被公司无故辞退怎么办"

```text
第1轮（定位）:   search_law({"query": "劳动合同法 违法解除 赔偿标准"})
第2轮（细化）:   search_law({"query": "劳动合同法 第四十八条 经济补偿金"})
第3轮（解释）:   search_law({"query": "最高法 劳动争议司法解释 违法解除"})
第4轮（地方）:   search_law({"query": "【用户所在省】 劳动争议 仲裁 时效"})
```

### 场景：用户问"签了购房合同想退房"

```text
第1轮（合同法）:       search_law({"query": "民法典 合同编 合同解除 条件"})
第2轮（商品房特别法）: search_law({"query": "商品房买卖合同司法解释 解除 退房"})
第3轮（违约金）:       search_law({"query": "买卖合同 违约金 调整 过高"})
第4轮（案例参考）:     search_law({"query": "商品房买卖 退房 违约金 典型案例"})
```

## 三、score_threshold 实战调参

| 情况 | 设置 | 原因 |
|------|------|------|
| 查具体法条编号 | `score_threshold: 0.7` | 法条编号是精确匹配，高分筛掉噪音 |
| 查某罪名量刑 | `score_threshold: 0.5` | 默认平衡 |
| 查"工伤认定"这种宽泛概念 | `score_threshold: 0.3` | 概念表述多样，低阈值扩大召回 |
| 检索无结果时 | 降到 `0.3` 并增大 `top_k: 5` | 扩大搜索范围 |

## 四、国际法律检索（scope: "international"）

### 触发场景

- 用户明确问国际条约（如 CISG、WTO、伯尔尼公约）
- 涉及跨境贸易、国际投资、国际仲裁
- 涉及外国法律（美国、欧盟、日本等）

### 检索示例

```text
# 国际贸易
search_law({"query": "CISG 根本违约 宣告合同无效", "scope": "international"})

# 知识产权
search_law({"query": "伯尔尼公约 著作权 保护期限", "scope": "international"})

# 数据合规
search_law({"query": "GDPR 数据主体权利 删除权", "scope": "international"})

# 国际仲裁
search_law({"query": "纽约公约 仲裁裁决 承认与执行", "scope": "international"})
```

### 涉内外交叉

当问题同时涉及国内法和国际法时：

```text
# 先查国内
search_law({"query": "涉外民事关系法律适用法 合同", "scope": "domestic"})

# 再查国际
search_law({"query": "CISG 合同成立 要约承诺", "scope": "international"})

# 综合分析两者的适用关系
```

## 五、常见反模式与修正

### 反模式：只用口语化表述

```text
❌ search_law({"query": "上班受伤了公司赔不赔"})
   → 语义太口语化，检索效果差

✅ search_law({"query": "工伤认定标准 工伤保险条例 赔偿"})
   → 法律术语 + 法规名称，精准匹配
```

### 反模式：一次查询涵盖太多问题

```text
❌ search_law({"query": "离婚财产分割子女抚养费精神损害赔偿"})
   → 一个 query 包含 3 个独立问题，结果不聚焦

✅ 分次查询：
   search_law({"query": "民法典 离婚 财产分割"})
   search_law({"query": "民法典 抚养费 计算标准"})
   search_law({"query": "民法典 离婚损害赔偿 条件"})
   → 分别检索，结果更精准
```

### 反模式：search_law 不可用时用网页搜索或凭记忆替代

```text
❌ search_law 工具不存在时，用通用网页搜索查法律条文
   → 可能返回过期、不准确或非权威来源的信息

❌ search_law 工具不存在时，凭模型记忆引用法条
   → 法律频繁修订，记忆不可靠

✅ search_law 工具不存在时，停止检索，引导用户安装 MCP：
   1. 告知用户需配置 aixllaw MCP 服务（免登录，无需 API Key）
   2. 按 SKILL.md Phase 1 的引导配置 ~/.codebuddy/mcp.json
   3. 重启 CodeBuddy / WorkBuddy 后重试
   4. 免登录额度用尽时，引导前往 https://portal.aixllaw.com/app/settings 注册升级

   详细配置指南参见 references/mcp-setup-guide.md
```
